# Phase 18: Agent Workflow

## Overview

Phase 18 introduces the Agent Workflow page, providing a clear visual overview of how ResearchPilot processes research papers and generates grounded AI outputs.

The page is designed as an informational workflow visualization rather than an interactive execution tool. It does not introduce fake agents, simulated execution, or unnecessary backend processing.

---

## Features Implemented

### 🔄 Core Research Pipeline

The Agent Workflow page visualizes the complete ResearchPilot processing pipeline:

- Document processing
- Document chunking
- Embedding generation
- Document-scoped vector storage
- Semantic evidence retrieval
- Grounded AI analysis
- Structured research output

Each stage explains its role in the overall research workflow.
